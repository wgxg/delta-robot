# Delta 机器人 6 自由度版本 —— 方案设计（DESIGN）

> 构型选型：**方案① 三主臂＋三副臂**（Fanuc M-3iA/6A 同类六轴 Delta）
> 前置版本：`../delta-3dof/`（PLCopen 架构重构完成，39+14+269 项测试全绿，commit 04119a0）
> 状态：P0~P3 全部完成。P2 ST 移植（6 个 .st + st_runtime.py + test_st6.py，13 场景逐拍对拍全绿）；**P3 集成回归完成（6DOF 360 项 + 3DOF 322 项 = 682 项全绿，M4 达成）**

---

## 1. 目标与继承原则

在 3 自由度 Delta（XYZ，仅位置）基础上扩展为 6 自由度（XYZ + RPY），**最大化复用现有资产**：

| 现有资产 | 6DOF 处置 |
|---|---|
| PLCopen 调度语义（Execute 上升沿、BufferMode 0/1/2、owner 令牌、wasWaiting 仲裁、信号锁存） | **逐行复用**，指令 FB 调度代码不改动 |
| `st_DeltaAxis` 共享轴结构 | 扩展为 `st_DeltaAxis6`（新增姿态与副臂字段，调度字段保持同名同义） |
| `FB_DeltaCore`（纯运动学引擎） | 同构复制为 `FB_DeltaCore6`，职责不变：只做运动学，不做调度 |
| 指令 FB（FB_PTP/LIN/CIR） | 复制为 FB_PTP6/LIN6/CIR6，只改轨迹初始化与插值部分 |
| 测试体系（test_delta / test_verify2 / test_matrix 模糊框架） | 框架复用，World/Sim 扩展为 6 电机 |
| IK 闭式解思路（tan 半角公式） | 每条链依旧一元二次闭式解 |

**硬约束（继承自 3DOF 项目约定）**：
- 指令 FB 与运动核心职责严格分离；核心不含任何 Execute/cmd 逻辑
- 每周期先执行所有指令 FB，最后执行核心
- 核心先使能一拍，指令 FB 的上升沿才被受理
- 机械参数唯一来源：核心发布到共享轴结构

## 2. 机械模型

### 2.1 构型描述

```
            顶板（固定）
      ┌────────────────────┐
      │  ◉主1  ◉副1  ◉主2  │   主电机×3：120° 分布，半径 R
      │  ◉主3      ◉副2..3 │   副电机×3：120° 分布，半径 Rc
      └────────────────────┘
        │主臂L    │副主动臂La
        ▼         ▼
        肘点       副肘点
        │从动杆l   │副连杆lb
        ▼         ▼
      ┌────────────────────┐
      │  ●主铰×3（半径 r） │   动平台（6DOF）
      │   ○副铰×3（半径 ra）│
      └────────────────────┘
```

- **主臂×3**：与 3DOF 完全相同。主电机绕水平切向轴摆动主动臂（长 L），肘点经从动杆（长 l）球铰连接动平台边缘 3 个主铰点（分布半径 r，120°）。
- **副臂×3**：副电机绕水平切向轴摆动**副主动臂**（长 La），副肘点经**副连杆**（长 lb）球铰连接动平台中心区域 3 个副铰点（分布半径 ra，120°）。副臂是与主臂同构的小型二连杆（副肘点行程可跟随平台 Z 向移动；单曲柄+定长杆的方案在近竖直杆下无法跟随 100mm 级行程，已否决）。副臂平面方位角与主臂相同（初版选择，参数可调）。
- 平台位姿由 6 条链联合约束：3 主链主导位置，3 副链主导姿态。

### 2.2 机械参数表（ST 源头 = 核心发布，指令 FB 不传参）

| 参数 | 含义 | 初值 | 备注 |
|---|---|---|---|
| R / r | 主电机基座 / 平台主铰分布半径 | 100 / 50 mm | 沿用 3DOF |
| L / l | 主主动臂 / 从动杆长 | 170 / 230 mm | 较 3DOF 加长（L+l=400 vs 350）：6DOF 主链平台铰点含 Rot·ai 姿态偏移，高 Z+倾斜角点沿用 350 预算超限（实测主铰点 w=361>350） |
| Rac | 副电机基座分布半径 | 100 mm | 角点全枚举扫描选定 |
| La | 副主动臂长 | 120 mm | 角点全枚举扫描选定；大 La 配大 lb 反使 lb 可行窗口收窄 |
| lb | 副连杆长 | 300 mm | 必须落在低 Z 弧上限与高 Z 弧下限构成的窗口内（实测 280 不可行 / 300 可行） |
| ra | 平台副铰分布半径 | 20 mm | 角点全枚举扫描选定 |
| Ph1 | 主电机方位角相位 | 0, ±120° | 固定 |
| Ph2 | 副电机方位角相位 | 0, ±120°（与主同相） | 可参数化 |

> 全部参数集中在 `st_DeltaAxis6`，由 `FB_DeltaCore6` 每周期发布；软件层不硬编码任何机械常数。

### 2.3 坐标系与位姿表示

- **基座系 O-XYZ**：原点在顶板中心，Z 轴**向下**为正（沿用 3DOF 约定；6DOF 工作空间见 2.4）。
- **平台系 o-xyz**：固连动平台，原点为平台几何中心。
- **姿态**：对外接口用 RPY（ZYX 固定角），旋转矩阵 R = Rz(C)·Ry(B)·Rx(A)；
  内部插补用**四元数**（slerp），避免欧拉角奇异与插补路径失真。
- **位姿六元组**：`(X, Y, Z, A, B, C)`，A/B/C 单位度。

### 2.4 工作空间与软限制（P0 实测）

6 自由度位姿由 6 链联合约束，工作空间是**位置-姿态耦合包络**（高 Z + 大倾角时主链杆长预算被 Rot·ai 偏移挤占），不再是 3DOF 式的独立矩形域。

**验证包络（角点全枚举 worst|c/m|≈0.83，作为测试随机域与软限制初值）**：

| 项 | 限制 |
|---|---|
| Z | 278 ~ 322 mm |
| 水平半径 ρ | ≤ 42 mm |
| roll / pitch | 各 ≤ 13°（组合倾角 ≤ 18.4°） |
| yaw | ≤ 25° |

**零姿态物理边界（二分法实测）**：中心 Z_max = 396.9 mm（与理论 √((L+l)²−r²) 吻合）；Z=300 平面 ρ_max = 187.7 mm；中心 roll_max = 89°；Z 下限 ≈269 mm 由副链低 Z 弧窗口决定。

> 行程较 3DOF 收窄是六轴 Delta 构型固有特性：副链为姿态提供约束的同时，其 lb 必须同时够到低 Z 弧与高 Z 弧，姿态被副链窗口进一步压缩。软限制按上述包络配置（可参数化），超出在指令受理时 Rejected。

## 3. 运动学（核心，选型①的根本理由）

### 3.1 符号

- 平台位姿：位置 `p`，姿态旋转矩阵 `Rot`。
- 主链 i：基座铰 `Bi`，肘点 `Ei(θi) = Bi + L·u(θi)`（u 在过 Bi 的竖直平面内单位圆），平台铰点 `Ai = p + Rot·ai`（ai 为平台系偏移）。
- 副链 j：基座铰 `Cj`（半径 Rac），副肘点 `Ej(φj) = Cj + La·u(φj)`（与主链同构），平台铰点 `Dj = p + Rot·dj`。

### 3.2 IK：位姿 → 6 电机角（**全闭式，无迭代**）

给定 `(p, Rot)`，6 条链**各自独立**求解，每条链一元二次方程：

```
主链：|Ei(θi) − Ai|² = l²   →  展开为 a·sinθi + b·cosθi = c
副链：|Ej(φj) − Dj|² = lb²  →  同型 a·sinφj + b·cosφj = c
```

统一闭式解：链平面内分解 u（径向）/ v（切向）/ w（Z）后 `m·cos(θ−α) = c`（m = hypot(u,w)，α = atan2(w,u)）→ `θ = α ± acos(c/m)`；有效性 |c| ≤ m 且 sinθ > 0（肘点在板下方），多解取距参考角最近者。

**与 3DOF IK 的唯一差别**：平台铰点从公共点 `(X,Y,Z)` 变为 `p + Rot·ai`——公式结构不变，仍闭式。
每周期 6 次三角函数 + 6 个二次方程，无迭代开销。

### 3.3 FK：6 电机角 → 位姿（牛顿迭代）

6 个约束方程、6 个未知量 `(X,Y,Z,A,B,C)`：

```
f_i(x) = |Ei(θi) − (p + Rot·ai)|² − l²   （i = 1..3）
g_j(x) = |Ej(φj) − (p + Rot·dj)|² − lb²  （j = 1..3）
```

- **解析雅可比**：`∂(Rot·a)/∂A|B|C` 用角速度叉积形式 `ω_k × (Rot·a)` 线性组合，无需数值差分。
- **初值 = 上一周期位姿**（温启动）。实测（10 万点 --full）：100% 收敛，tol=1e-8 下主分布 3~4 次；冷启动初值**必须带姿态偏置**——零姿态下 ∂(Rot·a)/∂A = x̂×a 对 ay=0 的链恒为 0，雅可比 A 列结构性退化，牛顿第一步即病态（2-guess 重试后 100% 收敛）。
- **列归一化预处理**：牛顿步解 (J·D⁻¹)(D·Δ) = f，消除位置 mm / 角度 rad 量纲差；奇异度指标 vol 同用列归一化后 |det| / Π行范数。
- **ST 精度策略**：tol = 1e-4 mm 实测 ≤8 次迭代收敛率 99.97%（max 9 次）——FK 仅服务 Cur 显示，1e-4 mm 足够。
- **收敛失败保护**：保留上次位姿 + 置 `FkError` 标志（对应 3DOF 的 IK 失败安全保持机制，监测逻辑同样用"累计漂移"判别）。
- **P1 关键发现——多装配解与 FK 初值策略（重要）**：六链 FK 与 3DOF 一样存在多组装配解，P0 的"100% 收敛"只验证残差收敛、不验证装配正确。P1 实测：
  - 纯牛顿温启动（初值=上拍 Cur）在带姿态的连续路径上会滑入另一装配根（LIN 段 60/510 周期姿态偏差 22°）；增加 **Levenberg-Marquardt 阻尼 + 残差严格单调线搜索**（`fk_track`，λ 自适应）后，因异根间隔 20°+ 且中间为高残差壁垒，无法跨越——但当路径**穿过 FK 折叠奇异（两装配根合并点，即 vol 退化区）**时，连续性跟踪会沿另一页平滑滑走（实测 i=146 起 0.1mm/拍单调发散，IK 全程成功无选支翻转）。
  - **最终策略：Busy 时以【规划位姿 Plan】为 FK 初值**（电机实际位姿必在 Plan 的伺服滞后邻域内，Plan 所在装配页即唯一正确页），LM 求解；冷启动用 DEFAULT_GUESS 纯牛顿。实测穿越折叠段最大 Cur−Plan 偏差 0.4 mm / 0.1°（纯伺服滞后），终点精确。**ST 移植时 FK 初值必须取 Plan，不可只取上拍 Cur。**
- **P2 ST 移植数值对齐要点（逐拍对拍实测）**：
  - 全量 **LREAL 双精度**；对外 Plan/Cur 的 A/B/C 用度，运动学边界 RAD()/DEG() 转弧度；方位常量 `cos/sin(2π/3)、cos/sin(4π/3)` 必须运行时计算（本机实测 cos2π/3 = −0.4999999999999998、cos4π/3 = −0.5000000000000004，硬编码 −0.5 即引入 1ULP 差）。
  - **求和对齐（关键坑）**：CPython 内建 `sum()` 对 float 并非朴素左结合（带部分和补偿），而 ST 累加器是朴素左结合。`fk_track` 的 4 处内建 sum 归约（JᵀJ 内积、Jᵀf、err0=Σfv²、e1=Σf1²）在纯平移 LIN 的近奇异姿态列（列范数 0.095 vs 位置列 23646，条件数 ~2.5e5）上差 1ULP，被病态放大为 FK 姿态输出逐拍发散（行程内 2.5e-11 → 1e-4 rad 且反号）。ST 侧这 4 处改用 **Neumaier 补偿求和**（17640 真实样本与 CPython sum / math.fsum 100% 逐位一致；Kahan 反而有 749 例不一致，不可用）。注意 Python 的列范数 cn 与 Mode2 `fk()` 全部归约本来就是朴素 `s += v*v` 循环，ST 对应点保持朴素，不可改。
  - 对拍以真实 .st 文件经 ST 子集解释器（st_runtime.py）加载执行，非重写仿真；13 场景（PTP/LIN/CIR/打断/缓存/拒绝脉冲/失能恢复/前馈/槽满清空/大行程/连段）逐拍 Tar/Plan/Cur 角差 < 1e-3、BOOL/INT 严格相等。
- **降级策略**：FK 仅服务 Cur 位姿显示/监控，若 ST 实时性吃紧可降为每 N 拍更新一次；IK/规划路径不依赖 FK。

### 3.4 奇异性与失效

- 几何不可达：任一链 |c| > |m|（同 3DOF 的 Disc<0）或副链 sinθ ≤ 0 → IK 失败保持。
- 姿态奇异：FK 用列归一化 vol 监测。注意构型固有退化：链 1 主铰点 (r,0,0) 绕 X 轴转动不变（对 roll 零敏感），纯 roll + yaw≈0 配置下 vol≈2.3e-4——不影响 IK 闭式解/前馈/收敛率，仅 FK 迭代稍多；vol 报警阈值设 1e-4，避免误报。
- 关节限位：任一解超出电机行程 → Rejected（指令受理阶段预检）。
- **FK 折叠奇异（P1 实测确认）**：带姿态路径可穿越两组 FK 装配解的合并点（vol 退化区，与 3.4 的固有退化相邻）。穿越时"连续性"不能保证装配页正确，只能靠规划位姿 Plan 锚定初值（见 3.3）；IK 闭式解与前馈在穿越全程始终正常。
- **缓存提升时几何/起点重建**：BufferMode=2 的等待指令在后续周期才提升为活动指令，其起点（PTP 关节角、LIN 起点位姿、CIR 圆弧几何）必须在【提升时刻】按实际 Cur 重建；上升沿只做 IK/圆弧非退化预检。否则等待者会从上一条指令途中的陈旧位置起算（P1 已修复）。

### 3.5 前馈

- 规划输出：`PlanVX/VY/VZ`（线速度）+ `PlanVA/VB/VC`（RPY 变化率）。
- 各链关节速度前馈：`q̇ = J_ik · [ṗ; (Ȧ,Ḃ,Ċ)]`，J_ik 为 IK 一元方程对位姿的解析导数行向量。
- 沿用现有 `FfEnable / Kff` 结构。P0 已实现精确形式（无欧拉率近似遗留）：
  `θ̇ = (Ak−Ek)·(ṗ + d(Rot·a)/dt) / [(Ak−Ek)·dEk/dθ]`，其中 `d(Rot·a)/dt = dA·Ȧ + dB·Ḃ + dC·Ċ`；
  S7 对拍（vs 数值中心差分，500 组随机位姿×随机旋量）误差 < 1e-5 rad/s 达标。

## 4. 软件架构（PLCopen 映射）

### 4.1 `st_DeltaAxis6` 字段清单

```iecst
TYPE st_DeltaAxis6 :
STRUCT
    (* --- 机械参数（仅核心写入） --- *)
    R, r, L, l       : REAL;
    Rac, ra, La, lb  : REAL;      (* 副臂四参数 *)
    CycleTime        : REAL;
    FfEnable         : BOOL;
    Kff              : REAL;
    Enable           : BOOL;

    (* --- 电机反馈（仿真/实际注入） --- *)
    CurTheta1..3     : REAL;      (* 主电机角 *)
    CurTheta4..6     : REAL;      (* 副电机角 *)

    (* --- 核心 FK 输出（实际位姿） --- *)
    CurX, CurY, CurZ : REAL;
    CurA, CurB, CurC : REAL;
    FkError          : BOOL;

    (* --- 规划输出（指令 FB 写，核心消费） --- *)
    PlanX, PlanY, PlanZ          : REAL;
    PlanA, PlanB, PlanC          : REAL;   (* 度 *)
    PlanVX, PlanVY, PlanVZ       : REAL;   (* mm/s *)
    PlanVA, PlanVB, PlanVC       : REAL;   (* 度/s *)

    (* --- 核心输出（目标电机角） --- *)
    TarTheta1..6     : REAL;

    (* --- 调度状态（与 3DOF 同名同义，逐字节复用语义） --- *)
    Busy       : BOOL;
    InPos      : BOOL;
    ActiveType : INT;             (* 0空闲 1=PTP 2=LIN 3=CIR *)
    owner      : DINT;            (* 控制权令牌 *)
    cmdCount   : DINT;
    hasBuf     : BOOL;            (* 缓存槽 *)
END_STRUCT
END_TYPE
```

### 4.2 功能块清单与职责

| FB | 职责 | 与 3DOF 差异 |
|---|---|---|
| `FB_DeltaCore6` | 发布参数；空闲跟随 Plan=Cur、PlanV=0；Busy 时 Tar=IK(Plan)+前馈；失能清零 | 同构复制 |
| `FB_DeltaKinematics6` | IK 6 链闭式 / FK 牛顿 / 前馈 | 全新（核心计算件） |
| `FB_PTP6` | 关节空间 6 轴同步插补（归一化 s 因子，与 3DOF 同算法） | 调度段逐行复用；初始化段算 6 个目标角 |
| `FB_LIN6` | 位置线性 + 姿态 slerp，每拍 IK | 调度段逐行复用；插值段新增四元数 slerp |
| `FB_CIR6` | 位置圆弧 + 姿态沿弧 slerp | 同上 |

### 4.3 指令语义（关键约定）

- **BufferMode 三模式不变**：0=运动中拒绝；1=打断（令牌易主，旧指令 CommandAborted）；2=单槽缓存（槽满 Rejected，等待者重触发释放槽位，wasWaiting 残留语义与 3DOF 修复版一致）。
- **信号语义不变**：InPos/CommandAborted 锁存到下次上升沿；Rejected 单周期脉冲；Busy 含缓存等待期。
- **PTP6**：目标位姿 `(X,Y,Z,A,B,C)` → IK 一次性得 6 个目标电机角 → 关节空间 s 插补（与 3DOF 完全同型，天然无姿态插补问题）。
- **LIN6**：位置 lerp + 姿态 slerp（四元数）；节拍 = max(平移耗时, 姿态耗时)；`Speed/Accel` 沿用 mm 等效量纲，新增姿态限速检查（软限制在受理时预检）。
- **CIR6**：圆心式/三点式（同 3DOF 两种模式）+ 姿态从起点到终点 slerp。
- **IK 预检**：指令受理（上升沿）时对目标位姿做一次 IK 试算，无解即 Rejected（3DOF 同机制）。

### 4.4 调用时序（不变）

```
每扫描周期：
  ① 依次调用所有指令 FB（FB_PTP6/FB_LIN6/FB_CIR6）—— 读 Cur*（上一拍核心结果），写 Plan*
  ② 最后调用 FB_DeltaCore6 —— 消费 Plan*，输出 Tar*
核心 Enable 失能→复位；重新使能第一拍仅使能，第二拍起指令上升沿才受理
```
